AuraCore v0.4.0 — Complete CLI reference and security guide.

Installation

# Clone repository git clone https://github.com/lamin-16/auracore.git cd auracore # Build with Mojo mkdir -p build mojo build src/cli_interface.mojo -o build/auracore # Add to PATH cp build/auracore ~/bin/auracore

Core Commands

CommandDescription
auracore initInitialize new encrypted vault
auracore startStart interactive AI agent session
auracore stopGracefully stop agent and lock vault
auracore statusShow agent runtime status
auracore encrypt-statusShow encryption diagnostics
auracore versionPrint version information
auracore helpPrint help text

Secret Management

CommandDescription
auracore store <key>Store a secret in the encrypted vault
auracore retrieve <key>Retrieve a secret from the vault

Backup Manager v0.2.0

Encrypted vault backups with automatic rotation. Maximum 5 backups stored.

CommandDescription
auracore backup createCreate new encrypted backup
auracore backup listList all available backups
auracore backup restore <file>Restore vault from backup
auracore backup verify <file>Verify backup integrity
auracore backup delete <file>Delete a backup file

Export Manager v0.3.0

Portable encrypted secret bundles with time-limited TTL (24 hours default).

CommandDescription
auracore export createExport secrets to encrypted bundle
auracore export listList all export files
auracore export import <file>Import secrets from bundle
auracore export revoke <file>Delete export before TTL expiry

FormatExtensionUse Case

Agent Config v0.4.0

Tune every aspect of the AI agent. Config stored encrypted at ~/.auracore/agent.cfg.enc.

CommandDescription
auracore agent-config showDisplay current configuration
auracore agent-config set <key> <val>Set a config value
auracore agent-config resetReset to defaults
auracore agent-config keysList all available keys

Security Architecture

Cryptographic Standards

EncryptionAES-256-GCM
Key DerivationPBKDF2-HMAC-SHA512
Iterations600,000
Salt256-bit random per vault
IV/Nonce96-bit random per lock()
Auth Tag128-bit GCM
StandardNIST SP 800-38D
ComplianceFIPS 140-3
