Core Features

🔐
Secure Vault
AES-256-GCM authenticated encryption with PBKDF2-HMAC-SHA512 key derivation. Your secrets never leave your device.
⚡
High Performance
Built in Mojo for native binary performance. Zero-allocation hot path with ring buffer token processing.
🤖
Local AI Agent
Connects to local LLM backends via Unix socket. Full context window management with 4096 token support.
🖥️
Clean CLI
English commands, German output. Intuitive interface for secure vault management and agent control.
💾
Secure Backup NEW
Encrypted vault backups with automatic rotation. Maximum 5 backups kept. Integrity verification before restore.
🛡️
Memory Safety
Explicit secure buffer zeroing after every cryptographic operation. No sensitive data left in heap memory.

Quick Start

# Initialize encrypted vault
$ auracore init

# Start AI agent session
$ auracore start

# Create encrypted backup
$ auracore backup create

# List all backups
$ auracore backup list

# Restore from backup
$ auracore backup restore vault_backup_20260922.enc

# Check encryption status
$ auracore encrypt-status
