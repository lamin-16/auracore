Core Features

🔐
Secure Vault
AES-256-GCM authenticated encryption with PBKDF2-HMAC-SHA512 key derivation. Your secrets never leave your device.
⚡
High Performance
Built in Mojo for native binary performance. Zero-allocation hot path with ring buffer token processing.
🤖
Local AI Agent
Connects to local LLM backends via Unix socket. Full context window management with 4096 token support.
💾
Secure Backup v0.2
Encrypted vault backups with automatic rotation. Max 5 backups. Integrity verification before restore.
📤
Export Manager v0.3
Portable encrypted secret bundles with 24h TTL. Three formats: .auraexp, .json.enc, .env.enc.
⚙️
Agent Config v0.4
Full agent tuning: model, temperature, threads, backend, persona, memory. Encrypted config persistence.

Quick Start

# Initialize encrypted vault
$ auracore init

# Configure AI agent
$ auracore agent-config set temperature 0.8

# Start agent session
$ auracore start

# Create encrypted backup
$ auracore backup create

# Export secrets securely
$ auracore export create

# Check encryption status
$ auracore encrypt-status
